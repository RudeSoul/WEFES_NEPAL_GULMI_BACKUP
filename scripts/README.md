# Maintenance & Utility Scripts (`scripts/`)

This directory contains standalone operational, seeding, and synchronization scripts.

---

## Catalog of Scripts
- `scripts/generate_ai_index.py`: Auto-generates the high-density `AI_INDEX.md` context file for AI assistants.
- `scripts/sync_data.py`: Downloads and verifies cryptographic SHA-256 checksums for heavy binary rasters from `data/manifest.json`.
- `scripts/extract_gulmi_palikas.py`: One-off GeoJSON boundary extraction utility.
- `scripts/process-palika-crops.py`: Tabular crop dataset aggregation script.
- `scripts/update-coffee-data.js`: Historical coffee statistics maintenance script.
