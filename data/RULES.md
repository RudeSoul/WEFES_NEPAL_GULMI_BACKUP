# Data Governance Rules (`data/RULES.md`)

## 1. Immutability of `data/real/`
- Source files in `data/real/` are **STRICTLY IMMUTABLE**.
- Automated code, scripts, or engines MUST NEVER write to, modify, or delete files in `data/real/`.

## 2. Reproducibility of `data/calculated/`
- Every file in `data/calculated/` must be generated by a registered engine or verified pipeline.
- Deleting any calculated artifact and running the engine must produce identical, bit-for-bit reproducible results.

## 3. Transparency of `data/proxy/`
- No proxy dataset may be added without a corresponding entry in `data/proxy/DATAINFO.md`.
- Every proxy must declare its source surrogate, confidence rating, limitations, and replacement criteria.

## 4. Mandatory `DATAINFO.md` in Subfolders
- Any newly created directory inside `data/` must include a `DATAINFO.md` declaring:
  1. Data Type (Real / Calculated / Proxy)
  2. Provenance & Source Organization
  3. Collection or Simulation Date
  4. Field Data Dictionary

## 5. Binary File Size Limits
- Files larger than 10 MB must NOT be committed to Git.
- Add their SHA-256 and download URL to `data/manifest.json`.
